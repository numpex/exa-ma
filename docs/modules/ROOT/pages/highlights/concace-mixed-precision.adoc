The CONCACE team combined a neural preconditioner applied in 32-bit arithmetic with a 64-bit iterative solver for acoustic wave propagation.
On 100 two-dimensional Helmholtz test cases, the solver reached a backward error of 10^-10^ in *fewer than 20 iterations*.

== A neural preconditioner for acoustic wave propagation

The team trained the neural network using the residual of the discretised equation. The same trained network served as a preconditioner across the test cases.
For those cases, GMRES without a preconditioner was still above the same error threshold after 1,024 iterations.
The results connect Exa-MA's work on xref:workpackages/wp2.adoc[scientific machine learning in WP2] and xref:workpackages/wp3.adoc[iterative solvers in WP3].

Luc Giraud, Carola Kruse, Paul Mycek, Maksym Shpakovych and Yanfei Xiang, _Neural Network Preconditioning: A Case Study for the Solution of the Parametric Helmholtz Equation_, Numerical Linear Algebra with Applications 33 (2026), e70123. https://doi.org/10.1002/nla.70123[Journal article] · https://arxiv.org/html/2610.16542v1#S4.F7[Convergence curves in Figure 7]

== Composyx on AMD and NVIDIA GPUs

In a separate benchmark, the CONCACE team used Composyx 1.7.1 with an additive Schwarz preconditioner for heterogeneous diffusion in three dimensions.
The benchmark measured weak scaling by growing the problem with the number of GPUs while keeping the number of subdomains per node fixed.

* *Adastra (HIP).* 89% weak-scaling efficiency on 128 nodes with 512 AMD MI250X GPUs and 217.5 million degrees of freedom.
* *Jean Zay (CUDA).* 88% weak-scaling efficiency on 32 nodes with 128 NVIDIA V100 GPUs.

== From French systems to EuroHPC

The CONCACE team extended its Composyx GPU campaign to JUPITER (NVIDIA) in Germany and LUMI (AMD) in Finland, with runs reaching *4,096 GPUs*.
On LUMI, the team reports that Composyx solved a linear system with *more than one billion unknowns in 90 seconds*.
The campaign is part of the team's preparation for Alice Recoque.
