== Overview

Forward-performance benchmark: solve the nonlinear thermo-electric high-field-magnet model at fixed accuracy and expose state fields, nonlinear/linear solver behaviour, device residency and CPU/APU performance; no inverse or control objective is introduced in this application.

== Methods & Algorithms

=== WP1: Discretization

* high-order cG/H1 and HDG
* full/partial/matrix-free assembly
* homogeneous worksets
* facets
* traces
* coupled blocks
* skeleton terms


=== WP3: Solvers

* PETSc/HPDDM Krylov solvers
* preconditioning
* nonlinear and block solvers
* device-resident sparse algebra

== Notes

Common forward operator used by all three applications: state y=(φ,T,ΔV), J=-σ(T;p)∇φ, ∇·J=0, -∇·(k(T;p)∇T)=J·E, V=0 on Γ-, V=ΔV on Γ+, ∫Γ+ J·n ds=Iset, with cooling boundary conditions. This row benchmarks only the forward map and its cG/H1 and HDG implementations. Grand Challenge AMD MI300A at CINES/Adastra: 319 MI300A in September-October 2026, then 128 MI300A from November 2026 for six months. Compare native Spack and Apptainer execution, CPU multicore and hybrid CPU+GPU/APU.
